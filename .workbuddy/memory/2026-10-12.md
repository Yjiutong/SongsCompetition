## 项目：共享歌单多人点歌（Cloudflare 静态站）
- 目标：把原单机的 `SongsCompetition.html`（歌曲淘汰赛）改成多人实时版——输入房间号进入、共同添加歌单、每人选歌、实时公示所有人的选择。
- 架构（纯 Cloudflare）：单一 Worker + Static Assets 托管 `public/`，每个房间一个 Durable Object (`Room`) 持有状态并用 Hibernatable WebSocket 实时广播。
  - `cloudflare/wrangler.toml`：assets 目录 = public，`[[durable_objects.bindings]]` ROOM，`[[migrations]]` v1 注册 Room。
  - `cloudflare/src/index.js`：路由 `/ws` 与 `/state` 到 DO，其余回退 `env.ASSETS.fetch`。
  - `cloudflare/src/room.js`：Room DO，`webSocketOpen/Message/Close`，`acceptWebSocket`，`serializeAttachment` 关联用户，广播 publicView。
  - `cloudflare/public/`：`index.html` + `style.css` + `app.js`，暗金主题，WebSocket 实时 + 4s 轮询回退。
- 部署：`cd cloudflare && npx wrangler@latest login && npx wrangler@latest deploy`。
- 环境限制：本机沙箱缺少 workerd 原生二进制，无法 `wrangler dev`/dry-run 实跑；仅做了 ESM 语法检查。用户侧需自行 deploy 验证。
