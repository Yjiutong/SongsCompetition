## Bug 修复：二选一界面白屏（约 22:10）
- 现象：进入 playing 后「你的对阵」面板空白（轮次条 `第 1/1 轮` 正常），「本轮所有人的选择」也不出内容。
- 根因：**前后端数据形状不一致**。`room.js` 的 `publicView()` 把本轮对阵输出为 `pairs: [{a, b, pick}]`（选择直接挂在每个对阵的 `pick` 上，`picks` 对象只存在于 DO 内部存储）；而 `app.js` 的 `renderPlaying()` 读的是 `mine.picks[idx]` → `undefined[0]` 抛 TypeError → `render()` 在渲染「你的对阵」时中断，`innerHTML` 刚被清空、卡片还没 append，于是面板空白且公示板也没轮到渲染。
- 修复：`public/app.js` 改为读 `pr.pick`；并顺手加固：
  - `render()` 拆成 `render()`（try/catch）+ `renderInner()`，任何渲染异常都会 console.error + toast 提示，不再静默白屏；
  - `renderPlaying()` 区分三种情况给出明确文案：身份同步中 / 旁观者（提示下一局自动参赛）/ 等待开局。
- 验证（本次新增两个临时脚本，位于 `.workbuddy/tmp/`，已加入 .gitignore，不参与部署）：
  - `.workbuddy/tmp/room.test.mjs`：mock DurableObjectState 驱动 Room 状态机走完整局（4 首→开始→各选2组→roundComplete→next_round→再选→finished→reset），20 项断言全过，确认后端契约。
  - `.workbuddy/tmp/render.test.mjs`：最小 DOM 沙箱里真跑 `public/app.js`，喂真实后端 payload，24 项断言全过：要牌面板渲染出 N 张 `.pair-card`、点击→后端记录→重渲染出现 `.picked` 金色高亮、公示板出现已选 chip、roundComplete 后「下一轮」可点、结束页显示每人歌名、坏 state 不白屏只弹提示。并复现旧代码 `mine.picks[0]` 必抛 TypeError，坐实根因。
- 运行方式：`node .workbuddy/tmp/room.test.mjs` / `node .workbuddy/tmp/render.test.mjs`（用托管 node 22；若无托管路径用系统 node 亦可）。

## 新增：网页缓存清除 + 房间空闲自动清理（约 22:16）
- 用户需求：① 网页缓存清除；② 房间 30 分钟无人在线则清除该房间的歌单缓存。
- 前端缓存：在 `src/index.js` 的 Worker 入口对页面静态资源（`/`、`index.html`、`app.js`、`style.css`、图片/字体等）返回 `Cache-Control: no-cache`，确保发布后浏览器/边缘不长期缓存旧脚本（正是之前「白屏 bug 反复出现」的根因之一）。`public/index.html` 房间头部新增「清除缓存」按钮 → `app.js` 的 `clearCache()` 带时间戳参数强制刷新页面。
- 房间空闲清理：`src/room.js` 用 Durable Object Alarm 实现 30 分钟无人在线清除歌单：`webSocketClose` 时若 `anyOnline` 为 false 则记 `emptySince` 并 `scheduleEviction`（setAlarm(emptySince+30min)）；`webSocketOpen`/`hello` 时 `cancelEviction`；新增 `alarm()`：仍有人 → 撤销；到点仍空 → 清空 songs + 重置对局（phase 回 collecting，保留离线参与者记录）+ 撤销 alarm。免费套餐默认支持 DO Alarm，无需 migration 改动。
- 测试扩展：`.workbuddy/tmp/room.test.mjs` 增加 [7][8] 空闲清理断言（最后一人离开排期 30min、到点清空歌单/重置对局/取消 alarm、有人回来即撤销）；新增 `.workbuddy/tmp/worker.test.mjs` 验证静态资源 no-cache 与 /ws//state 走 DO。三套测试全过（room 29 项、render 24 项、worker 7 项）。MockStorage 补 setAlarm/deleteAlarm/getAlarm。
- README 功能特性补两条（缓存清除、空闲自动清理）。
- 注意：`.workbuddy/tmp/` 已加入 .gitignore，测试脚本不会随 git 推到 Cloudflare。
